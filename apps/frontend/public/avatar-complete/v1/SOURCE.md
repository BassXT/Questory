# Questory Complete Avatar Presets

Created for the private Questory family installation on 2026-07-26 with the
OpenAI built-in image generation tool.

The production set contains eight complete child avatar presets and eight
independent animal companions. All source generations used a Questory-owned
AI-generated style reference, a single-subject prompt and a removable chroma
background. The final PNG files were background-removed, normalized to a
shared canvas and visually reviewed before integration.

Character canvas: 768 x 1152 pixels.

Pet canvas: 640 x 640 pixels.

The assets are intentionally complete illustrations rather than interchangeable
body layers. This keeps silhouettes and clothing coherent while the application
offers a simple character plus companion picker.
